# 工作流概览

## 1. 目标
本工作流用于把一个商品连锁需求稳定推进成：
- 3 份正式方案文档
- 1 份质量门禁报告

## 2. 五个阶段
1. 范围分诊
2. 需求分析
3. 概要技术方案
4. 详细技术方案
5. 质量门禁

其中：
- 5 个阶段由工作流包内置子 skill 完成

## 3. 协调方式
顶层 skill `requirement-to-plan-workflow-starter` 直接承担协调逻辑：
- 顺序调用前 5 个子 skill
- 若 gate `退回修改`，根据 gate 生成的指导文档从指定阶段重跑
- gate 最多执行 3 轮

## 4. 正式产物
- 需求分析文档
- 概要技术方案
- 详细技术方案
- 方案落地质量门禁报告

## 5. 审查依据
`requirement-analysis`、`solution-outline`、`solution-detail` 3 个阶段除正式文档外，还需要同步生成 `review-basis` 文档，供质量门禁审查使用。

## 6. 边界
本工作流到“详细技术方案 + 质量门禁”即止，不进入实现任务拆解和代码实现。
