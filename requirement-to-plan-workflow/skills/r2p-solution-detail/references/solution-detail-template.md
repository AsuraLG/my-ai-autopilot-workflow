## 6. 接口设计
### 6.1 对外提供 RPC 接口
要求：使用结构化格式，每个接口必须包含——
- 服务名（Thrift service name）
- 方法名
- 入参结构（字段名、类型、是否必填、说明）
- 出参结构（字段名、类型、说明）
- 异常码 / 错误码定义
- 幂等性说明（如适用）

### 6.2 对外提供 HTTP 接口（如适用）
要求：每个接口必须包含——
- path、method
- request body（字段名、类型、是否必填、说明）
- response body（字段名、类型、说明）
- 状态码定义

### 6.3 外部依赖接口
要求：每个依赖必须包含——
- 依赖的服务名和方法名
- 关键入参说明
- 预期返回结构
- 超时和重试策略

### 6.4 内部模块间接口（如适用）
### 6.5 MQ 消息设计（如适用）
要求：每个消息必须包含——
- Topic 名称
- 消息格式（JSON schema 或结构体定义）
- 生产方 / 消费方
- 消息触发条件
- 消费幂等策略
